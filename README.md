# hexese-studio/.github

Organisation-wide files for [Hexese](https://hexese.com):

- `profile/README.md` is the public profile shown on
  [github.com/hexese-studio](https://github.com/hexese-studio); its graphics live in
  `profile/assets/` (light and dark variants, see `profile/assets/NOTICE.md`).
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` and
  `.github/` (issue forms, pull request template) are the defaults for every
  repository of the organisation that does not ship its own.

Changes follow the same flow as every repository here: issue, branch from
`staging`, pull request into `staging`, merge commit, release pull request to `main`.
