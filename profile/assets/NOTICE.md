# Notes on the profile graphics

- Text in the SVGs is converted to outlines from **Outfit** and **JetBrains Mono**
  (both SIL Open Font License 1.1), so no font file is loaded.
- Brand marks in the stack row and the channel links are paths from
  **Simple Icons** (CC0 1.0); the LinkedIn mark is a plain path. Every mark is a
  trademark of its owner and is shown only to point to a tool or a profile.
- The Hexese and Amtsorakel marks are our own.
- The two screenshots show hexese.com and amtsorakel.de as captured on
  24 November 2026.
- Motion is CSS or SMIL inside each file; `prefers-reduced-motion` stops the
  CSS animations.
